# Практическая работа № 1

Решения заданий из файла «Практическая работа 1-2.pdf».

| Задание | Класс |
|---|---|
| 3. Сумма и среднее массива, цикл for | `Task03ArrayFor` |
| 4. Ввод массива, do while и while, минимум и максимум | `Task04ArrayInput` |
| 5. Аргументы командной строки | `Task05CommandLine` |
| 6. Первые 10 членов гармонического ряда | `Task06HarmonicSeries` |
| 7. Факториал с помощью метода и цикла | `Task07Factorial` |

Откройте папку проекта в IntelliJ IDEA, выберите установленный JDK 17 или новее и конфигурацию с номером задания, затем нажмите Run.

Для задания 4 введите размер массива, затем его элементы. Для задания 5 аргументы заданы в конфигурации запуска. Для задания 7 введите число от 0 до 20; отдельная конфигурация «Проверка факториала» проверяет метод.
