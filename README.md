# Практическая работа № 1

**Тема:** знакомство со средой разработки, синтаксис и основные управляющие конструкции Java.

Решены все программные задания из файла «Практическая работа 1-2.pdf», страница 11 (печатная страница 14). В предоставленном файле есть только задания практической работы № 1.

## Состав проекта

| Пункт | Класс | Что делает |
|---|---|---|
| 3 | `practice1.Task03ArrayFor` | Создаёт массив инициализацией, считает сумму через `for` и среднее |
| 4 | `practice1.Task04ArrayInput` | Читает массив с клавиатуры, считает сумму через `do while` и `while`, находит минимум и максимум |
| 5 | `practice1.Task05CommandLine` | Выводит аргументы командной строки через `for` |
| 6 | `practice1.Task06HarmonicSeries` | Печатает первые 10 членов ряда `1/n` с шестью знаками после точки |
| 7 | `practice1.Task07Factorial` | Вычисляет факториал отдельным статическим методом с циклом |

Исходный код находится в `src/practice1`, проверка метода факториала — в `test/practice1`.

## Запуск в IntelliJ IDEA

1. Откройте папку `java-practice-1` через **File → Open**.
2. При запросе SDK выберите установленный JDK 17 или новее. На этом компьютере настроен `openjdk-27`; на другом компьютере его нужно заменить своим SDK в **File → Project Structure → Project**.
3. Выберите готовую конфигурацию запуска с номером задания в верхней панели и нажмите **Run**. Либо откройте нужный класс и нажмите зелёный треугольник рядом с `main`.
4. Для задания 4 введите в консоли сначала размер, затем элементы через пробел или перевод строки. Пример: `5`, затем `3 -2 7 0 14`.
5. Для задания 5 уже заданы аргументы `Java 123 "Привет мир"`. Их можно изменить в конфигурации запуска в поле **Program arguments**.
6. Для задания 7 введите число от 0 до 20. Конфигурация «Проверка факториала» отдельно запускает 8 проверок метода.

Сторонние библиотеки, Maven и Gradle не требуются. Код проверен компилятором OpenJDK 27 с целевой версией Java 17.

## Пояснения к решению

- Сумма хранится в `long`, чтобы сумма нескольких значений `int` не переполнялась.
- В среднем используется `(double) sum`, чтобы деление сохраняло дробную часть.
- Минимум и максимум инициализируются первым элементом массива. Это правильно работает и для массива, состоящего только из отрицательных чисел.
- Размер массива должен быть положительным: это позволяет безопасно обращаться к первому элементу и использовать `do while`.
- В задании 6 используется `1.0 / n`, поскольку `1 / n` выполняло бы целочисленное деление.
- Факториал хранится в `long`: `20!` помещается в этот тип, `21!` — нет. Метод проверяет диапазон 0–20; для `0!` цикл не выполняется и возвращается 1.
- Некорректный ввод сопровождается сообщением об ошибке, после чего программа завершается.
